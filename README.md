# Face Scan: Heart Rate Monitor website

This is a build-free static website. Upload the complete folder to any standard web server; the server entry point is `index.html`.

Before deployment, edit `site-config.js` and replace the two `https://example.com/...` values with the final Privacy Policy and Terms of Service URLs. The header links will then take visitors to those pages.

No build, package installation, or server-side configuration is required.
